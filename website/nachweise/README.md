# Nachweise zur Website

Hier liegen Belege, die für den Betrieb der Website gebraucht werden und nicht auf der Website selbst
erscheinen. Dateinamen mit Datum, zum Beispiel `github-support-2026-10-01.pdf`.

| Nachweis | Woher | Status |
|---|---|---|
| Antwort des GitHub-Supports zur Zulässigkeit der Unternehmensseite auf GitHub Pages und zur Geltung des Data Protection Agreement | Ticket nach `website/offene-punkte.md`, Abschnitt A | offen |
| Freigabe der Rechtstexte (Impressum, Datenschutzerklärung, AGB) durch den Rechtsprüfer | Prüfpaket `website/pruefpaket-rechtstexte.pdf` | offen |
| Lizenz des Zahnräder-Stockfotos und Einwilligung zum Porträt | Betreiber | offen |
| Auftragsverarbeitungsvertrag oder Bestätigung des Hosters, sobald geklärt | Hoster | offen |
| DNS-Einträge der .com vor der Umstellung (Screenshot, Rückweg) | Canva, Domains, DNS-Einträge | offen |
